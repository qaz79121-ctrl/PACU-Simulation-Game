# PACU 藥物任務站

本專案是一套恢復室（PACU）藥物安全 2D 情境模擬遊戲，內容僅供教育訓練。

## 主要功能

- 練習模式與評量模式
- SIM-01 至 SIM-11 藥物情境
- 護理師點擊設備後走到指定位置並停留
- 病人評估、告知醫師、核對醫囑、洗手、選藥、配置、雙人核對、給藥、監測、再次洗手及電子紀錄
- 牆面生理監視器顯示 HR、BP、SpO₂、RR
- 給藥劑量計算、安全回饋及結果紀錄

## 直接開啟

開啟 `dist/index.html` 即可使用已建置版本。

## 開發與測試

需求：Node.js 18 或更新版本。

```bash
npm test
npm run build
```

原始碼位於 `src/`，測試位於 `tests/`，建置結果輸出至 `dist/`。

## 教育聲明

本模擬內容僅供教育訓練。實際臨床處置應依醫囑、院內規範、最新藥品資料及專業判斷執行。
